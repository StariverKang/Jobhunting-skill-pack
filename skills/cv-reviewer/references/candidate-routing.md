# 候选人档次与材料形态路由

## 目录

1. 分类原则
2. 三档候选人
3. 总量与密度矩阵
4. 单条经历路由
5. 信息不足时的补问

## 1. 分类原则

先分别判断候选人成熟度和材料形态，再组合决策。候选人成熟度不是年龄或公司名排序；材料形态也不是候选人能力判断。

判断证据包括：目标岗位是否明确、是否有可复述的完整项目、责任范围、方法深度、结果强度、外部验证、成长连续性、同生态位高信号经历数量。

## 2. 三档候选人

### 起步型

典型信号：0–2 段有限正式经历；校园、课程、个人项目占主要部分；结果多为作品、完成、入选、用户反馈或小范围采用。

审查目标：建立第一次机会所需的可信叙事。

- 选择一个目标方向，不同时扮演多个职业身份。
- 把非正式经历翻译为岗位证据，但保留其真实场景。
- 重点展示主动性、学习速度、问题意识、作品和外部反馈。
- 不要求每段都有复杂业务结果；要求每段至少有问题、行动/工具链和可观察产出。
- P2 应给出未来 1–2 个最高价值的证据获取动作。

### 成长型

典型信号：有多段不同大小的实习、项目或工作；能看出任务难度、平台、责任、方法或结果逐步升级，但方向可能分散。

审查目标：把散点整理为成长叙事，让转折与升级自然通向目标岗位。

- 找到 3–4 个成长节点，而不是罗列全部经历。
- 标出每个节点新增了什么：行业理解、方法、责任、协作或结果。
- 允许保留一个“非标准但关键”的转折经历，解释其对后续成长的作用。
- 旧节点压缩证明起点，新节点详细证明当前能力。
- 个性锚点应贯穿路线，例如持续服务同类用户、持续做某类问题或反复使用某种方法。

### 冲刺型

典型信号：多段强相关或平行重要的高信号履历；已有成熟项目和指标；目标岗位、公司层级或业务问题较明确。

审查目标：降低噪声，形成高命中、可快速比较的证据组合。

- 从目标岗位反推证据，不从履历数量出发。
- 主经历控制在能互补证明核心要求的范围，通常 3–5 段。
- 所有主经历采用两层“总—分”；总述通俗，分述专业。
- 背景、前置条件、因果、工具链、结果与 Hook 不得缺位。
- 跨行业经历只保留可迁移机制和高价值结果；相似生态位去重。
- 底部能力区只补充正文未完整呈现、但目标岗位会筛选的能力。

## 3. 总量与密度矩阵

| 材料组合 | 主要风险 | 默认策略 |
|---|---|---|
| 过少 + 单薄 | 无法证明叙事 | 证据挖掘、补问、保留最小闭环、给作品/项目补强计划 |
| 过少 + 丰富 | 一段承担过多能力 | 把最强段作为支柱，内部按能力主题拆分，用底部能力区补广度 |
| 适中 + 单薄 | 每段像职责清单 | 找 2–3 段补足问题、工具链、交付与反馈；其余压缩 |
| 适中 + 丰富 | 信息密度失控 | 选支柱/证明/补充，限制每段证明任务，分配不同篇幅 |
| 过多 + 单薄 | 重复和短期跳动 | 按目标能力聚类，同生态位去重，删除没有信息增量的段落 |
| 过多 + 丰富 | 所有经历争夺注意力 | 目标岗位反推、主证据前置、支持证据压缩、跨行业避重就轻 |
| 混合 | 强弱段落格式相同 | 逐段路由，禁止平均分配篇幅 |

“过少/过多”由一页或两页内能否形成完整、非重复的岗位证据决定，不使用绝对数量一刀切。

## 4. 单条经历路由

### 单薄

若只有机构、Title 和一句动作：

1. 识别真实场景与对象；
2. 追问为什么做、怎么做、用了什么、交付给谁、有什么反馈；
3. 有一个完整闭环时写 1 个强分点；
4. 仍无信息时压缩为一行或删除，不自动补成完整业务项目。

### 适中

写一层总述与 2–3 个互补能力点。每个点只承担一个主要证明任务。

### 丰富

先拆素材，不直接扩写：

- 核心问题与业务目标；
- 2–4 条相互独立的能力链；
- 最强结果与外部影响；
- 可转移到目标岗位的机制；
- 1–2 个可追问 Hook。

如果一段包含多个独立项目，只有在时间、角色和目标确实不同且拆开更利于理解时才拆分；否则保留同一经历下的项目模块。

## 5. 信息不足时的补问

每次最多问 3 个高信息量问题，优先级为：

1. 当时要解决什么问题，谁受到影响？
2. 你具体做了哪些关键判断和动作，使用了什么工具链？
3. 最终交付、反馈、采用、数据变化或下一步是什么？

不要先追问所有数字。对于起步型候选人，作品、被采用、被选中、重复使用、用户反馈和能力提升也可成为结果。
