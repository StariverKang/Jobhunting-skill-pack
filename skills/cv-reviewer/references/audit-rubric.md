# 分档审查量表

先选候选人档次，再使用对应 100 分量表。分数用于版本比较，不预测录取率。

## 起步型（100）

- **目标叙事 25**：方向单一可理解；现有材料能支持；下一步岗位自然。
- **证据挖掘 20**：校园、课程、项目和作品被正确转为证据；没有假装企业职责。
- **问题—工具链—结果 20**：支柱材料形成最小闭环；工具与准确动作相连。
- **个性锚点 15**：有相关、可解释、可记忆的个人特质或长期行动。
- **HR 可读性 10**：顶部和首句能快速理解潜力与方向。
- **证据补强计划 5**：下一步动作具体、优先级明确。
- **版面 5**：不过度留白或灌水，作品入口清楚。

## 成长型（100）

- **成长叙事 25**：能看出问题、责任、专业深度或平台逐段升级。
- **目标岗位匹配 20**：成长路线自然通向目标，最相关节点前置。
- **问题—工具链—结果 20**：核心经历有完整闭环和业务含义。
- **取舍与容量 10**：旧节点压缩，重复经历删除，篇幅不平均分配。
- **个性连续性 10**：有贯穿路线的用户、问题或方法偏好。
- **结果与 Hook 10**：数字或交付可解释，保留可追问的转折与难题。
- **版面 5**：层级稳定，成长节点容易扫描。

## 冲刺型（100）

- **目标精度 25**：直接命中目标岗位核心业务问题与关键筛选项。
- **高信号取舍 20**：平行强履历互补而不重复，跨行业避重就轻。
- **两层总—分 20**：每段总述通俗、分述专业，背景和前置条件完整。
- **因果、工具链与结果 15**：动作有原因、取舍、方法和业务影响。
- **Hook 与业务深度 10**：每段有可追问点且候选人能展开。
- **标准化与低理解成本 5**：Title、日期、标题、指标口径一致。
- **版面 5**：重点前置、底部能力点精确、不拥挤。

## 通用优先级

- `P0`：档次或叙事判断错误、顶部无法理解、核心方向混乱、支柱证据缺失。
- `P1`：容量失衡、单段结构薄弱、行业语言错误、成长节点不清或强履历重复。
- `P2`：下一阶段证据、作品、项目深度、岗位补强或面试 Hook 建设。

同一问题只出现一次。每条结论必须包含位置、问题、影响和直接改法。
