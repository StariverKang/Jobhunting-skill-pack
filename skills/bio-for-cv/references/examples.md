## 示例一：海外 AI 产品营销

事实摘要：传播学背景；做过海外 AI 产品社媒、KOL 合作和数据复盘；英文用于实际内容协作；目标公司正在拓展海外消费者市场。

```text
1. 传播学背景，熟悉海外AI产品营销、内容运营与用户增长，能够从平台语境、用户需求和产品卖点三个维度理解TikTok、Instagram等渠道的增长机会，并识别不同市场和用户阶段的内容差异
2. 海外增长能力扎实，能够完成KOL画像与筛选、定制合作、内容策划、发布跟踪和效果复盘，并依据账号、内容与转化数据持续优化获客路径
3. 网感好且兼具数据意识，能够捕捉平台热点、用户情绪和渠道差异，将信号转化为选题、英文文案与合作策略，并在快速迭代中校准品牌曝光和增长目标
4. 英语可作为工作语言，能够完成英文营销文案、跨文化沟通和多地区协作，并通过周度数据跟踪、问题复盘、交付节奏管理与跨团队对齐保证内容质量
```

## 示例二：产品运营

事实摘要：完成用户调研、需求拆解、跨团队推进、上线验证和运营复盘；目标岗位负责校园协作产品的增长与迭代。

```text
1. 具备从用户问题识别、需求拆解到上线运营的完整产品能力，熟悉校园协作与内容社区场景，能够衔接产品设计、开发验证、运营反馈和增长迭代，并理解隐私、协作与内容治理边界
2. 产品分析能力扎实，能够通过用户访谈、行为反馈、竞品拆解和数据复盘识别核心问题，形成清晰的需求优先级、产品方案、验证标准与迭代依据
3. 产品sense较好，兼具业务视角、用户视角与技术视角，能够把业务目标、体验问题和开发边界转化为需求说明、交互规则及迭代路径，并判断方案价值与实施成本
4. 跨团队推进与闭环意识较强，能够完成需求澄清、任务拆解、设计研发对齐、上线验收和效果复盘，并根据用户反馈调整产品细节与运营策略，沉淀可复用的需求记录与迭代结论
```

## 示例三：Web3 产品运营

事实摘要：参与钱包拉新活动配置、社区运营和链上数据复盘；目标公司是全球交易平台。

```text
1. 熟悉Web3交易平台、钱包产品与海外社区生态，具备产品运营、内容营销和用户增长的复合能力，能够理解活动参与、资产交互与社区传播的基本业务链路，并识别不同市场中的用户动机与风险特征
2. 能够完成活动配置、KOL拓展、合作沟通、链上数据追踪与竞品分析，并把零散运营动作沉淀为标准流程、指标看板和可执行复盘结论
3. 兼具海外内容敏感度与数据意识，能够撰写英文社媒文案、识别不同渠道的用户信号，并结合互动、转化和链上活跃数据调整传播与增长策略
4. 具备高频市场环境下的协作与风险意识，能够推进活动宣发、用户筛查、奖励发放和多团队对齐，并通过节点检查、流程沉淀和异常复盘控制预算与交付质量
```

## 示例四：科技投资分析

事实摘要：一段经历涉及 Web3 交易所竞品、营销表现与链上数据分析；另一段独立比赛获得 MCM 数学建模奖项。二者没有项目、因果或时间承接关系。

```text
1. 复合学科背景，熟悉科技、Web3与数字平台商业模式，兼具公司研究、行业分析和定量建模能力，能够从产品、用户、竞争和财务表现等维度建立研究框架
2. 科技行业研究与业务分析能力扎实，能够通过Desk Research、Benchmark和Top-down/Bottom-up拆解市场空间、竞争格局、增长驱动与公司基本面
3. 具备结构化研究与定量分析能力，能够完成问题建模、数据处理、数值求解和Scenario/Sensitivity检验，并将量化结果转化为可解释的投资判断与风险假设
4. 长文本研究与观点表达能力突出，能够整合多源资料、业务指标与模型结果，形成个股筛选逻辑、行业跟踪框架、深度报告和结构清晰的讨论材料
```

## 示例五：AI 品牌市场

事实摘要：不同经历分别证明 AI 产品营销、达人合作、内容生产、数据复盘和模型 API 实操；目标岗位负责大模型品牌内容、达人投放与效果分析。

```text
1. 熟悉AI产品海外营销、社媒内容运营与产品落地，兼具内容增长、用户洞察和模型应用能力，能够从产品价值、用户语境与渠道数据三个层面理解传播问题
2. 内容创意与达人营销能力扎实，能够围绕AI产品完成选题、模型case策划、达人画像与筛选、合作内容设计、发布跟踪和效果复盘，并持续优化品牌曝光与增长目标
3. 兼具AI实操、数据分析与产品理解，掌握Prompt Engineering，理解RAG的检索增强机制，能够调用模型API完成素材生产与信息处理，并通过Evals和用户反馈评估应用效果
4. 跨团队协作与英文交付能力较强，能够整合产品卖点、模型能力、用户反馈和投放数据，形成英文brief、官号内容、达人合作方案及阶段性效果报告
```

## 示例六：跨境电商战略与 PMO

事实摘要：候选人做过制造业项目节点推进、风险跟踪、会议材料整理，以及互联网指标复盘、竞品拆解和英文内容；原简历没有逐字写 WBS、RAID、WBR、MBR 或 Benchmark。目标岗位负责跨境电商卖家增长与内部战略项目。

```text
1. 兼具项目推进、互联网运营与市场研究能力，熟悉跨境电商的卖家、流量、转化与经营分析问题，能够从业务目标、用户行为和执行依赖三侧理解增长机会
2. PMO式项目推进与经营分析能力扎实，可用WBS拆解里程碑、以RAID跟踪风险依赖，并通过KPI Tree与WBR/MBR复盘目标、偏差、责任项和后续动作
3. 兼具市场研究与英文商业表达，能够用Benchmark、Funnel和敏感性分析拆解竞对策略、卖家分层与转化链路，形成结构清晰的业务洞察及英文材料
4. 数据敏感度与跨团队推进能力较强，能够围绕GMV、流量、转化、留存和激励机制组织月度分析，协调相关方完成资料补齐、问题定位与行动项跟进
```

这里的 WBS、RAID、WBR/MBR、Benchmark 和 Funnel 属于对已有动作的方法论命名或前瞻能力，不代表候选人在某段经历中正式采用过这些机制；因此使用“PMO式、可用、能够用、可将”，不写“曾搭建、熟练使用、主导”。

## 示例七：互联网平台运营与经营分析

事实摘要：教育经历已在简历上方展示，专业为金融学；做过交易平台运营、用户反馈、活动复盘、数据分析和 AI 提效。

```text
1. 金融学背景，熟悉平台运营、用户增长、流量分发与经营分析，兼具业务视角、用户视角与产品视角，能够把复杂问题转化为可分析框架
2. 数据分析与复盘能力扎实，能够编写SQL查询并通过Power BI整理资源位、活动链路、用户反馈和转化数据，完成清洗、归因与复盘，形成可追踪的结论和优化建议
3. 产品sense与用户sense较好，熟悉用户生命周期与平台运营机制，能够结合市场信号判断拉新、激活和留存问题，将用户行为、业务目标和竞品差异转化为运营策略
4. 兼具经营分析与结构化表达能力，能够围绕指标监控、竞品跟踪和用户分层组织专题研究，运用Prompt Engineering规范提纲、校验信息并提升分析效率
```

这组表达保留了平台运营、用户增长、流量分发、经营分析、SQL、Power BI、用户生命周期与 Prompt Engineering 等关键行业信号，也通过“产品sense、用户sense、多视角”展示候选人的工作判断；院校名没有重复出现。

## 流程回归：学历去重、自然语感与术语覆盖

- **错误**：`上海财经大学金融学背景，兼具平台运营与数据分析能力`。教育经历已在简历上方展示，院校名不再提供新信息。
- **正确**：`金融学背景，熟悉平台运营、用户增长与经营分析，兼具业务视角、用户视角与产品视角`。专业背景、关键能力域和自然语感同时保留。
- **错误**：`懂互联网和AI，网感好，产品sense不错`。过度删除行业术语后，HR 无法判断具体能力边界，自然语言也没有行为支撑。
- **正确**：`熟悉产品运营、客户服务、流程运营、SaaS解决方案与GTM，兼具业务视角、用户视角与产品思维，能够把用户需求转化为可落地的产品与运营动作`。关键能力版图先完成 HR 分类，多视角表达再说明工作方式。
- **正确 AI 分类说明**：`了解NLP、LLM与RAG等技术原理，熟悉CoT等推理方法，具备Agent/Workflow的场景诊断与基础设计能力`。关键词没有被删掉，也没有被统称为“AI工具”。

## 不合格示例

- `学习能力强，责任心强，抗压能力强`：没有行为证据，也不形成岗位定位。
- `精通AI、RAG、Agent与全部主流模型`：工具堆砌且强度无法证明。
- `看好公司前景，认同企业文化`：没有候选人能力信息。
- `公司正在出海，拥有大量海外营销经验`：把公司事实错误归因给候选人。
- 面向互联网 HR 只写陌生平台名和“竞品与数据分析”：没有说明它们是 Web3 交易所或钱包产品，目标读者无法快速判断行业与能力。
- `完成交易平台竞品、营销表现及链上数据分析，并获MCM数学建模奖`：没有说明交易平台属于 Web3 交易所，还错误暗示业务分析与比赛奖项属于同一经历。
- 第二、三条都以“曾负责/曾参与/完成过某项目”开头：即使事实正确，也仍在复述履历，没有回答候选人稳定具备什么能力、能承担哪些任务。
- 四条都重复“AI、海外、增长”：没有完成定义、证明、区分和定向的分工。
- 为接近 120 字而添加同义形容词：长度增加，但信息密度没有提高。
- 为显得专业而连续堆叠十余个缩写：读者无法判断任务、对象和结果，属于术语噪音。

## 流程回归：关键词分类、谓词与枚举

- **错误**：`熟悉Prompt、RAG、SQL、Python等工具`。Prompt是输入文本或提示设计方法，RAG是AI技术，SQL是查询语言，Python是编程语言，不能共享“熟悉……等工具”这一分类与谓词。
- **正确**：`掌握Prompt Engineering，理解RAG的检索增强机制，能够编写SQL查询并用Python处理数据`。每个关键词都获得了与其类别和实际操作相符的谓词。
- **错误**：`熟悉FastAPI、React等工具`。FastAPI是Web框架，React是前端库，且“熟悉”没有交代实际动作。
- **正确**：`能够使用FastAPI搭建接口，并基于React完成前端组件开发`。框架、库和对应任务之间的关系清楚。
- **错误**：`能够完成达人建联、活动策划、内容brief、会议SOP和阶段复盘`。一个“完成”同时统领动作、文档与复盘，主谓宾搭配生硬。
- **正确**：`能够推进达人建联与活动策划，撰写内容brief，沉淀会议SOP并开展阶段复盘`。并列动作符合真实工作顺序和中文语法。

## 流程回归：自然总分结构与术语完整性

- **错误**：`具备海外数字获客能力：能够追踪数据并复盘漏斗`。冒号把能力标签和说明句硬拆开，不符合简历顶部个人总结的自然句式。
- **正确**：`具备海外数字获客能力，能够追踪周度数据、复盘转化漏斗并提出优化建议`。中心能力直接进入句子，再由谓语展开任务链。
- **错误**：`熟悉内容—KOL链路与英文物料产出`。破折号拼接的名词关系不清，后半句也缺少与前文共享的中心词。
- **正确**：`熟悉海外社媒内容运营、KOL合作及英文文案撰写`。三个并列项都保持完整搭配。
- **错误**：`可将英文 Copy 经验用于广告投放`。来源中的 `Copywriting` 被截断后改变了动作含义。
- **正确**：`可将英文文案撰写经验用于广告投放`。压缩句子但不压坏术语。

## 流程回归：能力摘要不能退化为经历摘要

- **错误**：`商业分析本科生，曾在近万人模拟投资赛中获赛区第3名（Top 1%），职业方向聚焦TMT行业研究`。具体比赛和排名抢占了职业定位，读者先看到一段经历而不是能力。
- **正确**：`商业分析背景，聚焦TMT行业研究，具备公司研究、行业分析与定量验证能力`。保留背景和方向，把比赛证据留在内部矩阵或经历正文。
- **错误**：`相关证据来自某交易平台实习和MCM获奖项目`。这是证据说明，不是个人总结。
- **正确**：`兼具市场研究与定量分析能力，能够完成竞品拆解、问题建模与敏感性分析`。只输出证据共同支持的稳定能力。

## 流程回归：职业定位与公司 JD 适配

- **错误职业定位**：`商业分析背景，定位TMT行业研究实习`。这里把“定位”误写成了求职意向。
- **正确职业定位**：`商业分析背景，熟悉A股、机器人、ESG与TMT领域的研究逻辑，兼具公司分析、行业研究和定量验证能力，能够从基本面、技术路径与经营数据建立系统判断`。目标行业 HR 可以据此形成清晰的专业归类，但正文没有解释要投什么。
- **错误公司适配**：`面向中小券商TMT组的覆盖研究，可将投资研究经验用于财务模型资料整理和产业链调研`。这里复述了组织与预期职责，主体不是候选人能力。
- **正确公司适配**：`长文本研究、英文商业表达与结构化沟通能力突出，能够持续产出市场周报、投资计划书和讨论材料，并通过多源信息交叉验证提炼核心观点、风险因素与后续跟踪重点`。被选择的能力与公司和 JD 高度相关，但成文仍是自我评价。

## 流程回归：投递条件不得阻塞

场景：JD 写“大三及以上、每周至少到岗四天、连续实习六个月”，履历已能支持岗位能力，但没有确认年级、到岗日期和排班。

- **正确行为**：直接依据 JD 与履历生成四条能力摘要，省略年级、到岗和排班；让候选人自行决定投递，并在后续招聘沟通中处理条件。
- **错误行为**：生成前追问“实际大几、能否按时到岗、每周能来几天、能否实习六个月”，或以未确认这些条件为由停止 Skill。
- **仅在另行请求时询问**：用户要求评估资格、撰写好友申请备注、填写申请表或明确表达到岗安排。
